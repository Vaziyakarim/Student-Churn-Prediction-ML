# Student Churn Prediction using Machine Learning

## Project Overview

This project focuses on analyzing learner engagement data and predicting student churn using machine learning techniques. The goal of the project is to identify students who are at risk of dropping out or disengaging from learning programs so that early intervention strategies can be implemented.

The project combines data analysis, visualization, feature engineering, and predictive modeling into a complete end-to-end machine learning workflow.

---

# Objectives

- Analyze student engagement and learning behavior
- Identify important factors influencing churn
- Build predictive machine learning models
- Compare model performance
- Generate actionable insights from data

---

# What Was Done in This Project

## Data Preprocessing
- Cleaned and prepared raw learner data
- Handled missing values and duplicate records
- Performed feature engineering
- Encoded categorical variables
- Prepared the dataset for machine learning

---

## Exploratory Data Analysis
Performed detailed analysis and visualization to better understand learner behavior and churn patterns.

### Visualizations Included
- Churn distribution analysis
- Correlation heatmap
- Engagement score analysis
- Opportunity duration analysis
- Model comparison graphs
- Feature importance visualization
- ROC Curve and Confusion Matrix

---

## Machine Learning Models Used

The following machine learning models were implemented and evaluated:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

---

# Key Insights

- Engagement score strongly affects student retention.
- Students with lower engagement are more likely to churn.
- Opportunity duration and signup timing influence learner behavior.
- Machine learning models can effectively identify at-risk learners early.

---

# Best Performing Model

Random Forest achieved the best overall performance among all implemented models and provided meaningful feature importance analysis.
